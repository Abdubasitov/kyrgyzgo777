# KyrgyzGo777 — сайт туркомпании

Проект строится частями (см. план ниже). Это — **Часть 1**: каркас,
дизайн-система и структура.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173

## Что уже готово (Часть 1)

- Vite + React + TypeScript
- Tailwind CSS v4 с токенами бренда в `src/index.css` (`@theme`)
- React Router: `/`, `/tours`, `/about`, `/contacts`, 404
- Header (с мобильным меню на Framer Motion) и Footer
- Базовая модель тура `src/types/tour.ts` — под неё будут построены
  каталог, карточка тура, карта маршрута и админ-панель

## Палитра (из логотипа)

| Токен | Hex | Где используется |
|---|---|---|
| `forest-950` | `#0A2415` | футер, самый тёмный фон |
| `forest-800` | `#0F3D22` | заголовки |
| `forest-600` | `#1D6B3B` | основной бренд-цвет, кнопки, ссылки |
| `forest-400` | `#4FA968` | акценты, "777" в логотипе |
| `route`      | `#3DDC73` | линия маршрута на карте (Часть 4) |
| `stone-50`   | `#F2F4EE` | фон страницы |
| `stone-300`  | `#D8D2BD` | границы, разделители (тёплый "войлочный" камень) |
| `gold`       | `#B8912F` | точечные акценты в духе орнамента юрты |

Шрифты: **Big Shoulders Display** (заголовки, плакатный стиль экспедиций)
+ **Manrope** (текст).

## Куда класть свои фото

Все фотографии — заглушки. Кладите файлы в `public/images/...` и меняйте
`src="..."` в компонентах (везде рядом стоит комментарий `TODO`):

- `public/images/logo.png` — логотип (сейчас вместо него иконка гор)
- `public/images/tours/*.jpg` — обложки и галереи туров (Часть 3-4)

## План частей

1. ✅ Каркас, дизайн-система, роутинг, Header/Footer — **вы здесь**
2. Главная страница: анимированный герой + подборка туров
3. Каталог туров: карточки, фильтры по региону/сложности
4. Страница тура: галерея + карта маршрута на OpenStreetMap (зелёная линия)
5. Слой данных: хранилище туров (Zustand + localStorage), общее для сайта и админки
6. Админ-панель: вход, список туров, добавление/редактирование/удаление, редактор точек маршрута
7. Доп. админ-функции, управление фото, и как позже подключить реальный backend (Django REST — под ваш стек)

Каждая часть — отдельное сообщение с готовым кодом, который добавляется
поверх текущего каркаса.
